# Reference implementations

Layer 4 of the [five layers](../adr/0024-five-layers.md): batteries-included agents for everyday use, built only on the SDKs. There is one, the [standard configuration](standard-configuration.md), implemented in each of Rust, TypeScript, Go and Python. The [reference checks](../../conformance/reference/README.md) and the ACP kit check all four the same way.
